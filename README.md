# QA Audit Toll

A web app for call-centre quality audits. QA auditors score agents' calls
against a scoring sheet, and agents log in to see their own results.

## Users
- **QA auditor**: audits calls and records scores
- **Agent**: views their own audit results

## Features
1. **Login:** auditors and agents log in with their own credentials and see only what their role allows.
2. **Select agent:** the auditor picks the agent's name from a list stored in the database.
3. **Score a call:** the auditor opens the scoring sheet and scores each parameter while listening to the call.
4. **Add notes:** the auditor records areas of improvement (AOI) and remarks for the audit.
5. **View my scores:** the agent filters their audits by week, month or year and sees score, auditor name, audit date, call number and remarks.
